SUPER CLASH — PWA

Cette version est préparée pour être installée sur l'écran d'accueil d'un iPhone/iPad.

Important : une PWA doit être servie depuis une adresse HTTPS (ou localhost).
Ouvrir simplement index.html depuis Fichiers ne suffit pas pour l'installation PWA.

Après hébergement :
1. Ouvrir l'adresse dans Safari.
2. Menu Partager.
3. « Sur l'écran d'accueil ».
4. Ajouter « Super Clash ».
5. Lancer l'icône comme une application.

Le service worker permet ensuite au jeu de fonctionner hors connexion après son premier chargement.
